# Pocket Engineer 0.5.0-rc2 — anonymous Render downloads

This corrective preview keeps the GitHub source repository private and delivers installers publicly from [Pocket Engineer on Render](https://pocket-engineer.onrender.com/). No GitHub account is needed for the Render download files. Build validation and post-publication anonymous access checks are recorded separately.

## Download and run

- [Android preview APK](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/PocketEngineer-0.5.0-android-preview.apk): Android 7+ with an updated System WebView; native C++ and all demos bundled, no INTERNET permission. Optimized but development-signed. Export history before replacing a differently signed preview.
- [Windows x64 ZIP](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/PocketEngineer-0.5.0-Windows-x64.zip): extract all files; open `Start-Pocket-Engineer.cmd`.
- [macOS universal ZIP](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/PocketEngineer-0.5.0-macOS-universal.zip): macOS 11+; extract, then open `Start-Pocket-Engineer.command`. Not notarized. CI executes Apple Silicon, not an Intel Mac.
- [Linux x64 ZIP](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/PocketEngineer-0.5.0-Linux-x64.zip): extract, then run `sh Start-Pocket-Engineer.sh`. Static C/C++ runtime for Ubuntu and NixOS compatibility.
- [Offline website ZIP](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/PocketEngineer-0.5.0-offline-website.zip): complete WASM site for localhost or HTTPS hosting, not double-clicked `file://` use. Desktop ZIPs provide the local launcher without needing Python or Node.

Keep the desktop launcher's terminal open. Executables are not code-signed; do not disable system-wide security protections. [SHA-256 checksums](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/SHA256SUMS.txt) and [build provenance](https://pocket-engineer.onrender.com/downloads/v0.5.0-rc2/BUILD_SOURCE.txt) identify exact files.

## What changed

Private GitHub release assets return 404 to anonymous visitors. Earlier authenticated CI downloads did not establish public availability. This release moves public delivery to a checksum-verified, versioned directory on the existing Render site. Repository visibility and signing credentials are unchanged.

Installers are excluded from service-worker caches, Android assets, desktop packages and the website ZIP, preventing recursive package growth. Download navigation bypasses the service worker so it cannot substitute the app's HTML for an APK, ZIP or checksum file. The desktop download workflow now uses unauthenticated requests to Render.

The 0.5 visual labs remain: clickable 2–6 variable K-maps, matrix forms, DC/AC/transient circuit drawing and analysis, state-machine diagrams, and thirteen signals/transform operations. Original demos contain 55 topics × three difficulties × 5,000 stored cases. Choose a category and difficulty, calibrate, run a page or all 5,000, cancel and export expected/actual values. RK4 filenames now load correctly.

Visit the site while connected and wait for **Ready offline**; then the same Render URL works in the same browser after a full offline restart. The complete cached app and demo bank are about 9.2 MB. New private profiles, first-ever offline visits, cleared storage and cache eviction cannot preserve an installation that is absent.
