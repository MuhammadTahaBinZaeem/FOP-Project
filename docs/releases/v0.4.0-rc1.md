# Pocket Engineer 0.4.0-rc1 — natural input and portable offline downloads

[Open on Render](https://pocket-engineer.onrender.com/) · [Download assets](https://github.com/MuhammadTahaBinZaeem/FOP-Project/releases/tag/v0.4.0-rc1) · [Test history](https://github.com/MuhammadTahaBinZaeem/FOP-Project/blob/main/docs/TEST_HISTORY.md)

This is a prerelease. It supports 55 bounded engineering problem families, not
every possible course question. The offline C++ interpreter now accepts more
human wording, number words, named circuit parameters, matrix notation, linear
systems and selected ODE notation. Clear problem types override mistaken
dropdowns; the original question and interpretation are shown. Ambiguous or
unsupported inputs require clarification instead of an invented answer.

## Choose your download

| Asset | Open after downloading |
| --- | --- |
| `PocketEngineer-0.4.0-android-preview.apk` | Android API 24+, arm64-v8a/x86_64, updated System WebView. Install the optimized, non-debuggable Release APK. Development-signed preview, not a production/store release. Native C++ and UI are bundled; no INTERNET permission or prior website visit is needed. |
| `PocketEngineer-0.4.0-Windows-x64.zip` | Extract the entire ZIP; open `Start-Pocket-Engineer.cmd`. Keep the terminal running. |
| `PocketEngineer-0.4.0-macOS-universal.zip` | macOS 11+, Intel/Apple Silicon. Extract; open `Start-Pocket-Engineer.command`. Keep the terminal running. |
| `PocketEngineer-0.4.0-Linux-x64.zip` | x86_64 Linux. Extract; run `sh Start-Pocket-Engineer.sh` in the extracted package folder. Statically linked C/C++ runtime; no Ubuntu loader or Nix compatibility wrapper required. |
| `PocketEngineer-0.4.0-offline-website.zip` | Complete WASM website for localhost/HTTPS hosting, not `file://`. For a ready-to-launch desktop application, choose your platform ZIP instead. |

The desktop launcher opens your default browser at a loopback-only address.
If automatic browser launch is unavailable, copy the address printed in the
terminal. No Python, Node, account, administrator access or internet connection
is required to run a desktop package. Port 8765 is preferred, with an available
port fallback; browser-local history is tied to that address/port.

The Linux package fixes the observed 0.3 Ubuntu-loader failure on NixOS. Its
downloaded CI artifact was executed unmodified on NixOS, including from a path
containing spaces. This is not a claim for all kernels or architectures.
Windows/macOS executables remain unsigned/not notarized; OS security warnings
can apply. Do not disable system-wide protections.

Android development certificates can differ between previews. An incompatible
certificate prevents an in-place upgrade; export important solutions first.
Uninstalling clears app-local history. A stable owner-controlled signing key is
still required for production updates; private keys are never included here.

`SHA256SUMS.txt` covers all five packages and `BUILD_SOURCE.txt`. Verify hashes
against this release before running a download. Assets are copied unchanged
from successful CI build artifacts; only outer filenames are clarified. The
separate website ZIP includes the compiled WASM engine and a versioned cache.

## Performance and remaining limits

Avoidable animated scrolling, forced keyboard opening and redundant visual work
were removed. Offscreen subject cards defer layout. Emulator jank is **not
resolved or relabelled as zero**: an isolated app scroll measured 149/149 janky
frames while a plain-text control in the same emulator measured 170/172. These
graphics-path measurements cannot establish physical-phone performance. A
software-renderer run blocked by a System UI ANR was rejected as invalid.

Physical low-end phones, stable production signing, Apple notarization, Windows
code signing and 16KB-page Android runtime validation remain open. Input support
is a documented bounded grammar, not an unrestricted natural-language model.
See the [hardening record](https://github.com/MuhammadTahaBinZaeem/FOP-Project/blob/main/docs/JANK_INPUT_DOWNLOADS_V4.md)
for failures, corrections and the subsequent public-download verification record.
