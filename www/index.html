What are we solving?

01 / INPUT

Ask naturally: “Find the determinant of [[1,2],[3,4]]” or “Solve 2(x+3)=x+11”. You can paste equations and use ×, ÷, π and ².

What this solver supports

Natural input uses bounded, offline C++ grammars, not an online language model. State the operation and its values. Missing or unsupported details need clarification; arbitrary word problems are not supported. Turn off automatic interpretation to use the selected type and exact syntax. Calculations use floating-point arithmetic unless stated otherwise.

    Visit once online, prepare offline access, then revisit this same Render address in the same browser without internet. On Android use Chrome’s “Install app”; on desktop use Chrome or Edge’s install menu. No separate local server is needed for the cached website.
