    Install this website
    On Android, use Chrome’s “Install app” or “Add to home screen.” On Windows, macOS and Linux, use the install option in Chrome or Edge. Other modern browsers can run the website offline after it finishes caching.
    Preparing offline files…
    Open once online and wait for “Ready offline.” Then reopen the same address without a connection. Browser storage can be cleared or evicted; a native Android install does not depend on browser caching.
    

    ⌘
    Native & portable builds
    Android uses the C++ engine through JNI. Windows, macOS and Linux packages include the native command-line engine and local website server.
    Download releases ↗
    Development builds and test reports are available in GitHub Actions. Check the platform notes before installing an APK.
    Builds & test evidence ↗
    

    Requires JavaScript and a browser with WebAssembly and Web Workers. Offline website installation requires HTTPS or localhost. No promise is made for every device or browser version.
