# Pocket Engineer identity

The pocket-and-circuit mark was generated with the built-in image-generation tool on 2026-09-06. No letter monogram or SVG is used. The untouched source is `pocket-engineer-master.png`; Android and web assets are generated with `npm ci && node tools/prepare_assets.mjs`. Original illustrations live in `design/illustrations`, outside all application bundles.

Final generation prompt:

> Use case: logo-brand. Create one distinctive, professional raster logo mark for Pocket Engineer, an offline engineering study app covering mathematics, circuit design and digital logic. Concept: a single elegant folded drafting ribbon forms an open pocket/cradle, with a precise small orange circuit node and one purposeful connection suggesting a problem becoming clear. An original symbol, not a letter P, not a monogram, not a generic gear, not a stock app icon. Strong, immediately readable compact silhouette with generous negative space, beautiful at 32 pixels. Flat solid deep forest green (#1b4538) and warm orange (#e79761) on a flat warm off-white (#f5f5ee) square background. Centered symbol occupying about 62 percent of square, equal generous margins for Android adaptive mask safe area. No text, no initials, no gradients, no shadows, no dimensional effects, no texture, no mockup, no watermark, no SVG. One finished mark, not a contact sheet. Output square high-quality bitmap.

PNG icons use a 16-color palette without dithering; the header uses a 192px WebP at quality 85. Illustration WebPs are 480px at quality 76. The build has a 1.5 MB limit for critical offline assets, including WASM. See `docs/generated/ASSET_SIZES.json` for measured bytes. Generated artwork is not a trademark clearance guarantee.
